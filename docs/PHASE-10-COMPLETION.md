# Phase 10 — QAVLIO AI

Server-side marketplace intelligence. The assistant searches real listings, cites QAVLIO policy, and never invents prices, sellers, or availability.

- `/ai-assistant` plus the **Ask QAVLIO** dock
- Natural-language search → validated intent → existing Search API
- Listing explanations, comparisons, seller title/description help
- Personalized recommendations with a cold-start fallback
- Support escalation tickets (`Open` → `Closed`)
- Admin `/admin/settings/ai` toggles, limits, and usage analytics
- API keys stay in backend environment variables only
